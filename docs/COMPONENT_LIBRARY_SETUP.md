## 📚 Quick Usage Examples

### Button with Icon
```jsx
import Button from './components/Button/Button';
import { FiHome } from 'react-icons/fi';

<Button variant="primary" icon={FiHome}>
  Click Me
</Button>
```

### Card Component
```jsx
import Card from './components/Card/Card';
import { FiUser } from 'react-icons/fi';

<Card
  title="Profile"
  icon={FiUser}
  description="Manage your account"
/>
```

### Alert Component
```jsx
import Alert from './components/Alert/Alert';

<Alert
  type="success"
  message="Changes saved successfully!"
/>
```

### Badge Component
```jsx
import Badge from './components/Badge/Badge';

<Badge variant="success" label="Active" />
```

## 🛠️ Customization

### Change Colors
Edit the gradient values in component CSS files:
```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```

### Add More Icons
```jsx
import { FiLock, FiShare2, FiDownload } from 'react-icons/fi';
```

### Create New Components
Follow the existing component pattern with:
- `ComponentName.js` (logic)
- `ComponentName.css` (styling)
